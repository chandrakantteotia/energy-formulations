# Energy Formulations — Premium Pharmaceutical Manufacturing Website

> **Precision in Formulation. Confidence in Every Partnership.**

High-end, conversion-focused corporate website for **Energy Formulations**, a pharmaceutical formulation and contract manufacturing enterprise.

---

## 🌟 Key Features

- **Cinematic Split Hero**: Precision typography, glowing status indicators, dual contextual CTAs, and floating glass micro-cards.
- **Interactive Custom Manufacturing Configurator**: 3-step dynamic requirement selector that pre-fills the lead generation system.
- **"Inside the Process" Animated Factory Journey**: 6-stage interactive walkthrough from raw material intake to final CoA batch release.
- **Searchable & Filterable Product Explorer**: Live search, category dropdowns, dosage form filters, and instant inquiry triggers.
- **Editorial Asymmetrical Infrastructure Gallery**: Full-screen interactive Lightbox with technical facility specifications.
- **High-Conversion Contact Experience**: Multi-field quote request with real-time validation and interactive celebratory submission state.
- **Fast Quote Modal & Sticky Actions**: Floating desktop trigger and mobile sticky bottom bar (`Call`, `WhatsApp`, `Quote`).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
